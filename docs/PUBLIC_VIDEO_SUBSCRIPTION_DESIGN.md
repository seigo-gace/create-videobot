# 公開動画収集 → 無料60秒サンプル → Stars月額見放題｜採用構想・設計 v0.1

更新: 2026-11-14 (JST)
位置付け: Master 2026-11-14 の会話に基づく **設計記録**。Source実装・Bot配備・Telegram本番公開の完了を意味しない。
親Project: TGtumbler / 既存リポジトリ `seigo-gace/create-videobot`。
既存の単品Stars有料動画販売とは**別の視聴方式**であり、従来の単品販売・手数料・返金・売上台帳・ステッカー販売を改変しない。

## 1. 目的と確定要求
- Userbotが**現在参加している公開チャンネル**の動画を取得し、CreateVdobot側で検索・再利用可能に整理する。
- 中国語の投稿本文・説明文を日本語に翻訳し、**原文と日本語説明の両方**を保存する。
- 各動画から異なるシーンの静止画**2枚**を切り出し、検索・一覧・内容確認に使用する。
- 収集動画から**約60秒の無料ストリーミング再生用サンプル**を作成し、既存「ビデオチャットの掲示板」の**トピック**を集客窓口として使う。
- サンプルの投稿には日本語紹介文と、Stars月額の**非公開動画見放題チャンネル**への導線を付ける。
- 非公開チャンネルは**1つ**用意する想定。会員はTelegram公式の有料招待リンクからStarsで30日単位の料金を支払い、会員期間中は同チャンネルのフル動画を視聴できる。
- 動画収集、無料サンプル、チャンネル見放題は**単品Stars有料動画販売の台帳や購入解除とは結合しない**。

## 2. 構成・責務

| 担当 | 責務 | 非責務 |
|---|---|---|
| 既存常駐Userbot（GateApp-Bot所有） | 既存セッションを使用し参加済み公開チャンネルから動画と原文・出典を取得 | 新規ログイン、別セッション起動、購入・投稿・販売 |
| CreateVdobot / Collection | 収集制御、重複排除、検索メタデータDB、動画保存参照 | Botの売上台帳、会員課金 |
| CreateVdobot / Processing | 中国語→日本語、サムネ2枚、約60秒のMP4/H.264サンプル作成、フル動画と紐付け | チャンネルの購読期間の独自計算 |
| CreateVdobot / Publication | 許諾済み動画の無料サンプルを既存掲示板の指定トピックへ投稿し有料招待リンクを添付、会員チャンネルにフル動画を投稿 | 元動画を無断で販売、複数チャンネルの自動増設 |
| 既存掲示板（GateApp-Bot） | 既存トピックと投稿先アドレスの正本を提供し、集客窓口を維持 | 月額料金・購読者台帳 |
| Telegram公式 Stars Subscription | 非公開チャンネルの有料招待リンク、課金・30日更新・参加資格 | グループ内トピック単位の課金 |

既存のBotとトピックの責務を変更しない。新しいBot、Webアプリ、独自ECを作らない。Userbotの資格情報・セッションは既存所有者のまま。

## 3. コンテンツ処理
1. 常駐Userbot経由で**参加済みかつ公開**のチャンネル一覧を取得。
2. 各投稿の動画・チャンネル・message_id・原文・取得日時を取得し、`(channel_id, message_id)` を重複判定キーにする。
3. 動画本体は動画ファイルとして保存し、DBにはファイル参照とメタ情報を保存する。本文は中国語原文を維持して日本語訳を別項目に保存する。未翻訳・翻訳失敗は明確に状態管理し、日本語訳として原文を偽装しない。
4. 動画の約25％・75％付近から静止画を各1枚生成し、DBに2つの参照を紐付ける。同じシーンになり得る短尺・静止動画では別時刻でも同一画に見えることがあるため、**異なる画像になる保証は実機確認事項**。
5. 掲載対象とした動画から約60秒のサンプルMP4を切り出す。Telegramクライアントで再生できる形式（原則MP4/H.264、必要に応じ変換）を使用する。短尺や異常ファイルの扱いは検証・運用判断を必要とする。
6. 公開用に日本語紹介文とサンプル、フル動画の対応関係を記録する。**収集＝自動公開ではない**。第三者動画については少なくとも商用再配信・編集・短縮利用を許されたものだけ掲載対象とする。
7. 自動巡回は既存の常駐Userbotへ要求するジョブとして後続接続可能とする。巡回間隔・過去分の対象範囲は**未決定**。現在ある収集コードの`maxPerChannel=100`は現行実装の1回の取得上限であり、Masterの確定収集範囲ではない。

## 4. ユーザー導線と公開動作
**会員未加入者**
1. 既存「ビデオチャットの掲示板」の指定トピックを開く。**新しいトピックの新設は未決定**。
2. 約60秒のストリーミング対応サンプルをTelegram内で再生する（単なるURLだけにしない）。
3. 日本語紹介文とインラインの「Stars月額見放題チャンネルへ」ボタンを押す。
4. Telegram公式のStars有料招待リンクの加入画面に進む。月額料金・購読条件はTelegramの画面で確認する。
5. 支払えば非公開チャンネルへ参加し、会員期間中に掲載されたフル動画および閲覧可能な過去投稿を視聴する。

**有料会員**
- フル動画の会員チャンネルへの通常投稿を閲覧する（各動画に別のStars購入を要求しない）。
- 更新期限・継続課金・未払いによる会員権失効はTelegram公式の有料チャンネル参加仕様に委ねる。Botが二重に月額課金・独自BANを行わない。
- 公式による強制退会や更新失敗の具体的挙動はTelegram実機で確認する（ソース上の想定をPASSにしない）。

## 5. 既存設計・APIとのマッピング
- 既存実装ブランチ: `chat/userbot-public-video-collect-20261114` / PR #6。
- `src/collection/publicChannelVideos.mjs`: 参加済み公開チャンネルを対象にDL要求を行うCollector。現在は常駐Userbotとの実IPC結線が未検証。
- `src/collection/pgPublicChannelVideos.mjs`, `sql/20261114_public_channel_videos.sql`: 検索情報（原文・日本語・サムネ参照を含む）。DBマイグレーション本番適用は未検証。
- `src/collection/videoEnrichment.mjs`: 中国語→日本語翻訳ポート、ffprobe/ffmpegによる2枚切り出し。実翻訳プロバイダ・実動画・媒体保存先との接続は未検証。
- **次に追加する候補責務**: 収集データに対する60秒Preview生成アダプタ、投稿先と会員チャンネルの実測ID解決、投稿記録と失敗時再実行の最小冪等処理。既存販売Wizardへの混入は禁止。
- 無料サンプル投稿: Telegram Bot API `sendVideo` に `message_thread_id`, `supports_streaming=true`, `reply_markup` を指定する構造。単にフラグをtrueにするだけでは元ファイルのストリーミング適合を保証しない。
- 公式購読: チャンネル向け `createChatSubscriptionInviteLink`。購読期間は`2592000`秒（30日）、公式Bot API価格範囲は1〜10000 Stars。Botに招待権限が必要。**トピックに月額課金を設定するのではない**。
- API出典: https://core.telegram.org/bots/api ; https://core.telegram.org/api/subscriptions ; https://telegram.org/blog/superchannels-star-reactions-subscriptions

## 6. データのつながり（論理）
- `source_video`: 既存`channel_id`/`message_id`、原文、日本語訳、保存先、サムネ2参照。
- `preview`: 元動画のキー、プレビューファイル参照、尺、生成状態。元動画との関連を切らない。
- `publication`: 元動画のキー、掲載区分(`sample`または`member_full`)、投稿先chat/thread、Telegram投稿ID、投稿状態。再試行による多重投稿を避ける。
- 購読権限はTelegram公式が所有する。**会員ごとの決済台帳や個人データの複製は今回新設しない**。
- 上記`preview`/`publication`は論理設計であり、**新規DBテーブル実装済みという意味ではない**。既存スキーマと照合して最少追加する。

## 8. 受入・検証
1. 正規常駐Userbotの同一セッションで公開チャンネルを読み、別ログインやOTPを要求しない。
2. 収集した複数動画を日本語の説明とサムネ2枚で検索でき、動画本体へ辿れる。
3. サンプルは掲示板トピックで約60秒をTelegram内でストリーミング視聴でき、ボタンは実際の有料招待リンクへ遷移する。
4. 支払い済みテストアカウントが会員チャンネルのフル動画を閲覧でき、未加入アカウントは閲覧できない。
5. 更新・期限切れを公式の実挙動で確認する。既存単品販売と既存掲示板投稿動線は回帰しない。
6. 投稿済み動画の再処理で重複掲載しない。失敗があっても収集済み動画と原文を消失させない。
7. 配備、実動画、公式Stars加入テストの証拠なしに「本番完成」としない。
